# FB quickstart

Start with [the FB harness](../../docs/fb/README.md) and [the workstream-first
start contract](../../docs/fb/start.md). When planning or evidence
is useful, start in whichever workstream matches the question. Product/User is
selected only for user needs or product questions, never as a universal intake
coordinator. Relevant workstreams create ready handoffs; the user then says
`$bfm`, which activates Product reconciliation and execution of approved scope.

Read [workflow.md](../../docs/fb/workflow.md) for the board/index/handoff order,
[evidence.md](../../docs/fb/evidence.md) before asking for review, and
[guardrails.md](../../docs/fb/guardrails.md) for safety and recovery. Use
[sessions.md](../../docs/fb/sessions.md) only when work must resume across a
thread handoff, checkpoint, or review.
Use the canonical beginner pause card in `guardrails.md` for approval waits or
genuine stops.
