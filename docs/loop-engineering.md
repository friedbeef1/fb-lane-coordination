# Loop Engineering

Loop Engineering is FB’s return discipline: do not close until the approved
goal, work, evidence, board, and repository truth agree, or each disagreement
is explicitly marked.

The canonical operating manual is [the FB harness](fb/README.md):

- [start.md](fb/start.md) — Project Start Brief, lane selection, approval.
- [workflow.md](fb/workflow.md) — BFM return loop and durable records.
- [evidence.md](fb/evidence.md) — review evidence and Verification Handoff.
- [guardrails.md](fb/guardrails.md) — recovery, safety, and Loop Learning.
- [sessions.md](fb/sessions.md) — durable task state, curated checkpoints, recall, review, and closeout.

This guide intentionally routes to the pack so the same rule is maintained once.
