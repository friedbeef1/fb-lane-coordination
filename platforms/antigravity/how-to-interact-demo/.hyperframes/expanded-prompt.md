# Antigravity 2.0 FB-Lane How-To Video

## Style Block

No project `design.md` exists, so the composition uses HyperFrames house-style direction with a dark premium technical palette: background `#0c0b09`, foreground `#f7efe0`, amber Antigravity accent `#f59e0b`, safety green `#34d399`, and lane colors for Tech `#60a5fa`, Design `#a78bfa`, Business `#2dd4bf`, Product `#f59e0b`. Typography pairs a high-contrast serif display stack (`Iowan Old Style`, `Georgia`) with system monospace for code, board rows, and labels.

## Rhythm Declaration

Pattern: hook-PROBLEM-define-BUILD-PEAK-board-resolve. The first beat establishes Antigravity's native power, the second makes the collision risk visible, the middle beats show Product defining and invoking agents, the board beat explains the awareness layer, and the final beat resolves into the promise: parallel by default, safe by design.

## Global Rules

- Duration: 42 seconds, 1280x720, 30fps.
- Build visual depth with radial glows, ghost words, orbit rings, grid grain, panels, and board rows.
- Use Antigravity-specific language: `define_subagent`, `invoke_subagent`, background agents, bounded tools, Product traffic control.
- Avoid presenting FB-Lane as the thing that creates parallelism. Antigravity already provides native parallel subagents; FB-Lane supplies boundaries, locks, board state, handoffs, and the Product merge gate.
- Keep text concise and large enough for video playback.

## Scene Beats

### 1. Title / Native Agents, Safe Coordination

Concept: The viewer enters a dark orchestration control room. Antigravity energy is represented by amber orbit rings and a subtle technical grid. The headline should land as a product promise, not an installation instruction.

Mood direction: cinematic operations console, premium developer-tool launch, editorial serif type against code-like metadata.

Depth layers: BG grid grain, amber radial glow, ghost `ANTIGRAVITY`, orbit ring; MG headline, subtitle, rule; FG lane pills.

Choreography: headline rises in, rule draws, pills cascade, orbit rotates slowly.

Transition out: blur fade into the problem beat.

### 2. Problem / Powerful Agents, No Traffic Control

Concept: Make the failure mode concrete. Two lane cards claim overlapping files and the collision stamp lands hard.

Mood direction: incident board, controlled alarm, not chaotic red-screen panic.

Depth layers: BG ghost `TOOL OVERLOAD`, MG problem copy and two file claim cards, FG collision stamp.

Choreography: text slides from left, cards slide from right, file chips pop, collision stamp punches in and vibrates.

Transition out: leftward blur to the setup beat.

### 3. Define / Register Specialist Lanes

Concept: Product turns native Antigravity subagents into bounded lanes. The code panel makes the mechanism feel real without becoming documentation-heavy.

Mood direction: command center code review, compact and precise.

Depth layers: BG ghost `DEFINE`, MG code console and explanatory copy, FG syntax accents.

Choreography: console slides in, code lines type/step in, copy follows from the right.

Transition out: upward blur.

### 4. Hub / Product Traffic Controller

Concept: Product is the central coordinator. Tech, Design, Business, and the gate orbit around it with connection lines.

Mood direction: agent network map, operational topology, clear hierarchy.

Depth layers: BG ghost `ORCHESTRATE`, MG Product hub, subagent nodes, connection lines, FG pulse on Product.

Choreography: core scales up, lines draw outward, nodes pop into place, hub pulses.

Transition out: rightward blur.

### 5. Lanes / Concurrent But Scoped

Concept: Three lanes run at the same time, but each lane has its own branch and locked files. This is the main proof that Antigravity parallelism and FB-Lane safety coexist.

Mood direction: deployment dashboard, calm concurrency, readable status cards.

Depth layers: BG ghost `CONCURRENT`, MG three lane cards with progress bars, FG status lines showing locks.

Choreography: cards rise staggered, progress bars fill, status lines appear, cards float subtly.

Transition out: upward blur.

### 6. Board / Awareness Layer

Concept: Separate background agents become aware through shared repo state. The board shows two safe claims and one rejected overlap.

Mood direction: source-of-truth table, crisp audit trail, explicit blocker.

Depth layers: BG ghost `PROJECT_BOARD`, MG board rows, explanatory copy, FG blocked status pulse.

Choreography: rows slide in, copy enters, blocked status pulses.

Transition out: zoom blur into the final promise.

### 7. Final / Parallel By Default, Safe By Design

Concept: Resolve the story. Antigravity runs agents; FB-Lane keeps Product in charge of scope, staging, sequencing, and conflict resolution.

Mood direction: confident product ending, operations complete, no marketing clutter.

Depth layers: BG orbit ring, ghost `SAFE PARALLEL`, MG headline/subtitle, FG three-step checklist.

Choreography: headline rises, checklist slides in, check numbers pop, orbit drifts.

## Recurring Motifs

- Amber orbit rings represent Antigravity's native agent runtime.
- Board rows and file chips represent FB-Lane's safety protocol.
- Green indicates safe claims and merge gates.
- Red appears only for rejected overlaps or collision risk.

## Negative Prompt

Avoid generic chat bubbles as the main metaphor; Antigravity should feel like native orchestration, not just another sidebar chat UI. Avoid purple-blue gradient dominance, tiny dashboard text, dense paragraphs, default Inter/Roboto styling, and claims that FB-Lane creates Antigravity's concurrency.
