# Claude Code How-To Demo

This HyperFrames composition explains how to interact with FB-Lane in Claude Code:

- direct lane tags such as `@fb-design`, `@fb-tech`, and `@fb-business`
- shared `PROJECT_BOARD.md` state
- file locks and lane branches
- Product/Captain sequencing and conflict resolution at the end

## Output

- Final MP4: [GitHub release asset](https://github.com/friedbeef1/fb-lane-coordination/releases/download/demo-assets-2026-06-27/claude-code-how-to-interact.mp4)
- Source composition: [`index.html`](index.html)
- Expanded prompt: [`.hyperframes/expanded-prompt.md`](.hyperframes/expanded-prompt.md)
